AC8翻译工具 · ACE COMBAT 8

双击“AC8翻译工具.exe”，无需安装 Python。
也可双击“AC8翻译工具.cmd”启动同目录的 EXE，无需 Python；EXE 可单独分享，CMD 须与 EXE 放在一起。
请放在有写入权限的普通文件夹中，workspace 保存在 EXE 旁，译文由你选择保存位置。
EXE 不包含个人译文；分享已完成的翻译时，请同时提供译文 JSON。

使用步骤
1. 工具自动从 Steam 库查找游戏目录，未找到或需要更换时手动选择。
2. “翻译文件”初始为空；点“导出文本”新建 JSON，或点“选择”打开已有译文。
3. 只填写译文列，保存为 UTF-8。翻译要求见“给AI的翻译说明.txt”。
4. 选择 HUD 和装备简称是否应用译文，点“校验译文”。
5. 点“译文对照”比较日英、原官中和你的译文。对照默认日英中，可改日英。
6. 退出游戏后点“导入译文”，游戏文字语言选择简体中文。
   导入时显示“正在导入，尚未完成，请勿关闭”；等窗口标题或日志显示“导入完成”，才表示全部写入并验证通过。
7. 需要恢复原文件时，退出游戏后点“撤回修改”。
“打开翻译文件”打开当前 JSON；“使用说明”打开本说明。
导出默认日英中，可改日英。默认文件名为 AC8翻译.json，首次保存使用系统默认位置。
选过文件后，对话框跟随所选文件的目录，不预选个人 JSON。
校验报告在 workspace/check-report.json，对照页面在 workspace/comparisons。
导出、校验和对照不会修改游戏。

导入选择
“导入 HUD 标牌译文”和“导入装备简称译文”默认不勾选，保留原标牌和简称。
HUD 包括目标框、呼号、仪表及短状态；装备简称可能由 HUD、科技树和机库共用。
当前识别 1,276 个 HUD 位置、228 个装备简称位置；未确认用途的位置不猜测排除。
剧情、无线电、教程及装备完整名称和说明照常翻译，同一条目的不同位置分别处理。
勾选对应选项才应用这些位置的译文；实际控件的中文显示仍需游戏内确认。
v1.0 取消误加的简报、机库 UI 保护，这些位置正常应用译文；只保留原有明确 HUD 标牌保护。
剧情、字幕及菜单标题仍应用译文。使用新版、保持“导入 HUD 标牌译文”不勾选并重新导入一次，调整才会生效。
每次导入按当前文件和开关重建，已填译文覆盖上次译文。
null 使用各位置原官中；将旧译文改为 null 后重新导入，也恢复原官中。
取消勾选再导入，会恢复相应原标牌；JSON 中的译文保留。
未填项不阻止导入，参与导入的已填项须通过格式检查。
旧分类文件已有的翻译范围、逐条排除和排除来源继续生效。

JSON 填写
columns 在顶部声明列顺序，rows 每行最后一列始终是译文。
日英：[序号, 日文, 英文, 译文]
日英中：[序号, 日文, 英文, 原官中参考, 译文]
英文为数字 0 表示与日文相同；译文为 null 表示未填写。
译文通常为字符串；空字符串也算已填写，仍须校验。不要改官中参考列。
官中参考为多项列表时，可填一个字符串统一替换，或填与参考列表等长的译文数组。
数组逐项对应参考版本，元素只能是字符串或 null；工具映射到各原始位置。
没有多版本参考的条目不能填写译文数组。
AI 可将 columns 改为 ["id","translation"]，每行仅返回 [序号,译文]。
其他顶部字段不变，全部序号必须齐全；可调整行顺序，不能新增、删除或重复序号。
含原文的文件只改译文列，保留日英原文、官中参考和版本字段。
旧完整文件只填 entries[].translation；完整、精简及旧分类 JSON 均继续兼容。
源码命令行保留 compact，可为旧文件另存精简副本；界面不再提供转换入口。

字符格式
保留 {Minutes} 等变量、<btn .../> 和 <color ...>、</> 等控制标签。
保留 PUA 图标字符、控制码、换行类型与数量，以及开头和结尾的空白。
JSON 双引号写成 \"，反斜杠写成 \\，换行写成 \n；文件保存为 UTF-8。
工具检查变量、标签、图标、换行、首尾空白与字体缺字。
字节长度和文本池终止符自动计算，无需手工修改。

备份与限制
导入会备份原文件并修改中文资源加载位置，备份在游戏目录 .AC8-Localization-backup。
撤回恢复首次导入前的游戏文件，不依赖 EXE 所在位置；撤回前不要删除备份。
工具拒绝不支持的版本、未知 EXE 改动和导入后的外部文件改动。
当前支持 Steam build 25201480；离线格式和副本验证已完成，实际游戏加载尚未验证。
工具不修改反作弊设置；联机前可用“撤回修改”恢复原文件。
项目使用 Git 管理版本，VERSION 记录版本号，CHANGELOG.md 记录历史。
恢复工具版本与撤回游戏修改是两项独立操作。
