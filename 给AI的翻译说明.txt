请结合日文和英文，为下面的游戏文本 JSON 填写简体中文译文。

翻译要求
以日文原意为基础，用英文核对语境、指代和军事表达。剧情对白须自然、准确，保留人物语气、情绪与信息，不生硬直译，不添加原文没有的设定。官中只供对照及变体映射，不作为重译底稿；日英不一致时结合上下文判断，不照抄官中。
人名、呼号、中队/组织名和地名按用户术语表或已确认的社区称呼统一，出现在对白中也保持一致。未确定的专名保留英文原名，无英文才保留日文，不自行音译；机型、武器型号、编号和缩写保留原写法。
按用户指定范围翻译；未指定范围时补齐所有未填条目，保留已有译文，除非用户要求重译。不自行按 HUD、菜单、剧情等类别跳过条目或添加分类。HUD 标牌和装备简称是否替换由工具导入开关控制，JSON 中保留译文即可。

输入与空值
按 columns 识别列顺序。默认日英中为 [序号,日文,英文,官中参考,译文]；日英为 [序号,日文,英文,译文]。译文始终在最后一列。英文数字 0 表示与日文相同，原文 null 表示缺少该语种。
译文通常为字符串。用户明确不替换或尚未完成的项用 null：导入会使用该位置原官中，上次译文也会被恢复，不沿用旧补丁。不要用空字符串 "" 表示未翻译，它会成为实际空文本。
仅当官中参考为多个不同变体的列表时，可填单个字符串统一替换，或填等长译文数组，按参考列表顺序对应；数组每项只能为字符串或 null。不要把多个译法拼在同一字符串里。官中参考及日英原文保持原样。

字符格式
格式参照由 format_sources["序号"] 指定 ja/en；未指定时用日文，日文缺失才用英文。按这一份参照保留格式，不混用日英两份格式，不擅改 format_sources 绕过校验。
完整保留变量名及数量（如 {Minutes}、%s）、标签与属性（如 <btn .../>、<color ...>、</>）、图标、控制字符及转义内容。保留换行类型和数量、首尾空白；按中文语义安排断行和标签包裹的文字，不随意删减。不要添加 NUL、装饰符号或生僻汉字。
使用正确 JSON 转义：双引号 \"，反斜杠 \\，换行 \n；不要把换行误写成可见的反斜杠加 n。保存为 UTF-8。

输出要求
为节省 token，将 columns 改为 ["id","translation"]，rows 每行仅返回 [原整数序号,译文]，不重复输出原文和官中。
其余顶部字段原样保留，尤其 source_revision、official_revision、format_sources 及旧文件的选择设置。保留输入的全部序号，不增删、重复或省略条目。
只返回完整有效的 JSON，不加注释、说明字段、解释或 Markdown 代码围栏。
