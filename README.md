# AC8翻译工具 · ACE COMBAT 8

当前发布版本为 **1.1**。窗口标题、主界面标题和导入状态均显示工具版本。

下载 **[AC8中文翻译1.1.zip](https://github.com/sheno4/AC8-Translation-Tool/releases/download/v1.1/AC8-1.1.zip)**，包含工具、两份 2026.10.21 AI 校订译文、使用说明和离线配置。请先完整解压。

Windows 64 位工具，用于导出日英文本、填写中文译文并替换游戏的官方简体中文。
双击 **AC8翻译工具.exe**，无需安装 Python。请将它放在有写入权限的普通文件夹中。
也可双击 **AC8翻译工具.cmd** 启动同目录的 EXE，无需 Python；EXE 可单独分享，CMD 须与 EXE 放在一起。
`workspace` 工作目录保存在 EXE 旁，译文由你选择保存位置；EXE 不包含个人译文。
分享已完成的翻译时，请同时提供译文 JSON。

## 使用步骤

1. 工具自动从 Steam 库查找 ACE COMBAT 8 游戏目录；未找到或需要更换时手动选择。
2. “翻译文件”初始为空。点“导出文本”新建 JSON，或点“选择”打开已有译文。
3. 只填写译文列，按 UTF-8 保存；可将“给AI的翻译说明.txt”与 JSON 一起交给翻译者。
4. 选择 HUD 和装备简称是否应用译文，再点“校验译文”。
5. 用“译文对照”比较日英原文、原官中和你的译文；可勾选条目并“复制选中 ID”，发给 AI 定位修改。
6. 退出游戏后点“导入译文”，游戏文字语言选择简体中文。
   导入时显示“正在导入，尚未完成，请勿关闭”；等窗口标题或日志显示“导入完成”，才表示全部写入并验证通过。
7. 需要恢复原文件时，退出游戏后点“撤回修改”。

“使用说明”打开操作说明。选择已有译文仍使用“翻译文件”旁的“选择”按钮。
对照页支持本页全选，翻页和筛选保留选择；复制结果为去重的 JSON 数字 ID 数组，如 `[12,37,105]`，对应当前翻译 JSON。
同一序号关联多个文本位置时同步勾选，复制时只保留一次。
导出默认文件名为 `AC8翻译.json`，首次保存使用系统默认位置；选过文件后，对话框跟随所选文件的目录。
导出和对照默认 **日英中**，均可改为 **日英**。官中是只读参考，不会自动填入译文。
校验报告保存在 `workspace/check-report.json`；对照页保存在 `workspace/comparisons`。
导出、校验和对照不会修改游戏。

## 导入选择

“导入 HUD 标牌译文”和“导入装备简称译文”默认不勾选，保留这些位置的原标牌或简称。
HUD 保护识别目标框、呼号、仪表及短状态；装备简称可能由 HUD、科技树和机库共用。
当前识别 1,277 个 HUD 位置和 228 个装备简称位置，未确认用途的位置不猜测排除。
剧情、无线电、教程、装备完整名称和说明照常应用译文。
同一条目在多个界面出现时，保护仅作用于已识别的位置。
勾选相应选项后才应用这些位置的译文。

简报、机库界面、剧情、字幕及菜单标题正常应用译文。回放 REX 标牌 CP:10157 默认保留英文，同名机库 CP:44561 继续应用中文译文。
使用新版并重新导入后，当前译文和导入选项才会生效。

每次导入按当前 JSON 和开关重新生成全部文本，已填译文覆盖上次译文。
`null` 使用该位置的原官中；将旧译文改回 `null` 再导入，也会恢复原官中。
取消 HUD 或装备简称勾选后重新导入，会恢复对应原标牌；JSON 中的译文继续保留。
未填项不会阻止导入，参与导入的已填项须通过格式检查。
旧分类文件已有的范围、逐条排除及排除来源继续生效。

## JSON 填写规则

新导出为精简格式，`columns` 声明列顺序，`rows` 每行最后一列是译文：

- 日英：`[序号, 日文, 英文, 译文]`
- 日英中：`[序号, 日文, 英文, 原官中参考, 译文]`
- 英文为数字 `0` 时表示与日文完全相同；译文为 `null` 时表示未填写。

译文填写字符串；空字符串也属于已填写，仍须校验。
官中参考是多项列表时，可用一个字符串统一替换，或填与参考列表等长的译文数组。
数组逐项对应参考版本，元素为字符串或 `null`；工具还原到各原始位置。
没有多版本参考的条目不能填写译文数组。

AI 可以只返回结果：将 `columns` 改为 `["id","translation"]`，每行写 `[序号,译文]`。
其他顶部字段保持原样，全部序号必须齐全；允许调整行顺序，不能新增、删除或重复序号。
含原文的文件只改译文列，不改日英原文、官中参考或版本字段。
旧完整文件仍填写 `entries[].translation`；完整、精简及旧分类 JSON 均继续兼容。
源码命令行仍保留 `compact`，可为旧文件另存精简副本；界面不再提供转换入口。

保留变量、控制标签、PUA 图标字符、控制码、换行类型与数量、首尾空白。
例如 `{Minutes}`、`<btn .../>`、`<color ...>` 与 `</>` 都应保持完整。
JSON 中双引号写成 `\"`，反斜杠写成 `\\`，换行写成 `\n`；保存为 UTF-8。
工具检查格式和字体缺字，UTF-8 字节长度及文本池终止符自动计算。

## 备份与版本

1.1 将译文生成的 `CP_M.dat`、`ON_M.dat` 打成独立 PAK，配合 `dinput8.dll` 加载器覆盖原中文资源，磁盘上的游戏 EXE 不修改。
加载器在运行时仅为本工具的 PAK 挂钩签名读取，不依赖 UE4SS。
从 1.0.x 升级时，重新导入会先恢复原游戏 EXE，再安装新资源补丁；撤回 1.1 会移除本工具安装的 PAK 和 DLL。
备份和安装记录在游戏目录 `.AC8-Localization-backup`，撤回前请保留。
导出、译文校验和对照使用内置原文库，不检查 Steam 版本或游戏文件，也无需选择游戏目录。
导入按当前 EXE 的加载器所需代码结构和八份相关文本资源检查兼容性，不锁定某个 Steam 构建版本或整份资源包的哈希。
游戏更新后，相关代码和文本保持兼容时可重新导入；结构或文本映射改变时会提示需要适配。
JSON 中的版本信息描述内置原文快照，已有译文文件继续兼容。
本工具不修改反作弊设置；联机前可通过“撤回修改”恢复原文件。
源码版本由 Git 管理，版本号见 `VERSION`，历史见 `CHANGELOG.md`。
恢复工具版本与撤回游戏修改是两项独立操作。

## 已知问题

部分 HUD／标牌缺少汉字字形，显示中文时可能出现乱码。

## 源码运行与打包

Windows 上安装带 Tcl/Tk 的 Python 3.12，运行 `python tool/gui.py`。
构建独立 EXE：

```powershell
python -m pip install -r requirements-build.txt
python build_exe.py
```

运行源码及构建产物仍会要求选择自己的游戏目录与翻译文件。
