## 简介

这是为 **ACE COMBAT 8** 制作的简体中文重译 Mod，用来替换游戏原有的官方中文。

**译文由 AI 结合日文和英文重新翻译、校订**，内容包括剧情对白、字幕、菜单和说明文本。可以直接使用包内译文，也可以导出文本，自行翻译或修改。

配套工具支持译文对照、HUD 标牌和装备简称的选择性导入，以及一键撤回。汉化以独立资源包加载，不修改磁盘上的游戏 EXE。

## 选择译文

压缩包包含两份 **2026.10.21 校订译文**，任选一份导入。

| 译文 | 翻译范围 |
| :--- | :--- |
| **完全重译** | 全部条目重新翻译 |
| **仅重译官中** | 重新翻译原本提供官方中文的条目，其余保留原文 |

## 安装

1. **退出游戏**，完整解压，打开 `AC8翻译工具.exe`。
2. 确认自动找到的游戏目录；在“翻译文件”处选择一份 JSON。
3. “导入 HUD 标牌译文”和“导入装备简称译文”保持默认不勾选，点击“校验译文”。
4. 校验通过后点击“导入译文”，**等待标题或日志显示“导入完成”**。
5. 按包内《使用方法》设置离线启动，进入游戏后将文字语言设为 **简体中文**。

默认保留 HUD 标牌和装备简称；剧情、字幕及普通菜单应用译文。

## 更换与撤回

- **更换译文**：退出游戏，选择另一份 JSON，重新校验并导入。本次选择会替换上次导入结果。
- **恢复原文**：退出游戏，点击“撤回修改”。

请保留游戏目录中的 `.AC8-Localization-backup`，撤回时会用到。

## 自己制作或修改译文

- 点击“导出文本”生成 JSON，默认包含日英中，可改为日英。
- 只填写译文列；变量、标签、图标、换行和首尾空白按原格式保留。
- 译文填 `null`，导入时使用该位置的原官中；将已有译文改回 `null` 后重新导入，也会恢复原官中。
- “译文对照”可比较原文与译文，多选条目后可复制 ID，交给 AI 定位修改。
- 填写后重新校验并导入，翻译要求见包内《给AI的翻译说明》。
